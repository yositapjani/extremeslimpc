ExtremeSlimPC

Extreme Windows 11 debloat + privacy hardening, as a single copy-paste command. One readable script, no mystery tool, no background service.

Run it

Run in Windows PowerShell as Administrator, then paste:

irm https://raw.githubusercontent.com/yositapjani/extremeslimpc/main/extremeslimpc.ps1 | iex

The script prints its plan, waits 10 seconds so you can cancel with Ctrl+C, then works through every section and logs to $env:TEMP\extremeslimpc.log. No reboot required. Review the script first on GitHub.

What it does

  • Removes 21 bundled apps (user + provisioned), including the Xbox stack: Bing News/Weather, Solitaire, To Do, Alarms, Sound Recorder, Zune Music, Feedback Hub, Get Help, Office Hub, Power Automate, Clipchamp, DevHome, Teams, Phone Link, new Outlook, Gaming App, Xbox overlays and identity.
  • Disables 14 services: telemetry (DiagTrack), geolocation, maps, Connected Devices / PIM sync, Insider, and Xbox services.
  • Disables 8 scheduled tasks: CEIP, Compatibility Appraiser, PcaPatchDbTask, StartupAppTask, Location, Maps toast, Disk Diagnostic collector.
  • Sets 14 privacy policies: telemetry 0, location Deny, no Start ads, no silent app installs, Cortana off, Bing search off, OneDrive blocked, Delivery Optimization HTTP-only, consumer features off.
  • Uninstalls OneDrive and removes Edge autostart and OneDrive tasks.

What it does NOT touch

  • Microsoft Store (kept on purpose, so removed apps can be reinstalled)
  • Windows Defender, Windows Update, printing, Search indexing, SysMain, runtimes
  • Your files, your Steam library, your drivers
Warning: Do not run this if you depend on OneDrive sync or on Xbox / Game Bar. Your OneDrive files are not deleted: a non-empty OneDrive folder is left untouched. Removed Store apps can be reinstalled from the Store.

Restore

To undo the services, tasks, and policies (apps must be reinstalled from the Store yourself), run as Administrator:

irm https://raw.githubusercontent.com/yositapjani/extremeslimpc/main/extremeslimpc-restore.ps1 | iex

Then reboot. Full documentation, including optional power-plan and pagefile guidance, is in the README.
